## 系统要求

### 2.1 硬件要求

#### 最小配置
- **CPU**: 双核 2.0GHz
- **内存**: 4GB RAM
- **存储**: 50GB 可用空间
- **网络**: 100Mbps

#### 推荐配置
- **CPU**: 四核 2.5GHz
- **内存**: 8GB RAM
- **存储**: 100GB SSD
- **网络**: 1Gbps

- **CPU**: 八核 3.0GHz
- **内存**: 16GB RAM
- **存储**: 500GB SSD + 2TB HDD（备份）
- **网络**: 1Gbps + 冗余

#### 操作系统
- Windows 10/11 专业版
- Windows Server 2016/2019/2022

#### 必要组件
- .NET Framework 4.7.2或更高
- Windows Update至最新
- 防病毒软件（配置白名单）

## 部署步骤

### 4.1 准备部署环境

```bash
# 1. 创建部署目录
mkdir C:\InventoryPro
cd C:\InventoryPro

# 2. 创建数据目录
mkdir data
mkdir data\backup
mkdir data\export
mkdir data\logs

# 3. 设置目录权限
icacls data /grant Users:(OI)(CI)F
icacls backup /grant "SYSTEM":(OI)(CI)F
```

### 4.2 部署应用程序

1. **复制程序文件**
   ```
   - InventoryPro.exe
   - 所有依赖DLL文件
   - 配置文件
   ```

2. **设置执行权限**
   ```cmd
   icacls InventoryPro.exe /grant Users:RX
   ```

3. **创建服务账户（可选）**
   ```cmd
   net user InvService /add
   net localgroup Users InvService /add
   ```

### 4.3 初始化数据库

1. **运行程序首次初始化**
   ```
   InventoryPro.exe --init-db
   ```

2. **导入基础数据**
   ```
   - 商品分类
   - 供应商信息
   - 仓库信息
   - 初始库存
   ```

3. **创建管理员账户**
   - 用户名：admin
   - 初始密码：需要立即修改
   - 角色：系统管理员

### 4.4 配置系统参数

编辑 `config.json`：
```json
{
  "database": {
    "path": "C:\\InventoryPro\\data\\inventory.db",
    "backup_path": "C:\\InventoryPro\\data\\backup",
    "auto_backup": true,
    "backup_interval": 24
  },
  "security": {
    "password_policy": {
      "min_length": 8,
      "require_complex": true,
      "expire_days": 90
    },
    "session_timeout": 30
  },
  "performance": {
    "cache_size": 1000,
    "query_timeout": 30
  }
}
```

## 配置说明

### 5.1 数据库配置

```ini
[Database]
# 数据库文件路径
Path=C:\InventoryPro\data\inventory.db
# 自动备份间隔（小时）
BackupInterval=24
# 备份保留天数
BackupRetention=30
# 启用WAL模式（提升并发性能）
EnableWAL=true
# 缓存大小（页数）
CacheSize=2000
```

### 5.2 日志配置

```ini
[Logging]
# 日志级别：DEBUG/INFO/WARN/ERROR
Level=INFO
# 日志文件路径
Path=C:\InventoryPro\data\logs\app.log
# 日志文件最大大小（MB）
MaxFileSize=10
# 日志保留天数
RetentionDays=30
```

### 5.3 性能配置

```ini
[Performance]
# 每页显示记录数
PageSize=100
# 查询超时时间（秒）
QueryTimeout=30
# 启用查询缓存
EnableCache=true
# 缓存过期时间（分钟）
CacheExpire=5
```
